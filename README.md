# Florisse

Loja online da Florisse, marca de cosméticos da Dayse Ulisses.

## Checklist de material

[`checklist/index.html`](checklist/index.html) é a lista do material que a cliente envia para o desenvolvimento do site: identidade visual, produtos, fotos, textos, dados do negócio e envios.

- Página estática, sem dependências: abra o arquivo no navegador ou publique com GitHub Pages.
- As marcações ficam guardadas no navegador de quem preenche (`localStorage`).
- O botão "Copiar resumo" gera a lista de enviados e pendentes para colar no WhatsApp.
